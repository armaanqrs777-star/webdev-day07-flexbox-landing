# 🧩 Day 07 - Flexbox Landing Page

A modern SaaS-style landing page built entirely with Flexbox layout.

## What I Learned
- Flexbox layout mastery (`justify-content`, `align-items`, `flex-wrap`, `gap`)
- Dark theme design
- Pricing cards with "popular" highlight
- FAQ section with `<details>` and `<summary>` tags
- Glow button effects
- Trust badges section
- Responsive flexbox layouts

## How to View
Open `index.html` in any web browser.
